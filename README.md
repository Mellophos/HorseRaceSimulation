# horse-racing-sim

**!  This project is currently under active development (vertical slice working)  !**

Python-based horse racing simulation.

## Goal

Adapting [Umamusume's](https://umamusume.com/) deep race simulation on a global scale.

## Soon-to-be Features

- Intricate race mechanics based off the [Umamusume](https://umamusume.com/) game
- Various real-life racetracks to choose from
- Support for custom racetracks.

## Roadmap

- [X] Functional Vertical Slice: load horses, race them on a course, and print results as text
- Core Simulation:
    - [ ] Speed Calculations
    - [ ] Lane Movement
- [ ] First Race Mechanic: Position Keeping (`simulation/mechanics/position_keep`)
- [ ] Documentation: Writing docstrings for functions and classes

## Installation Steps

Work in progress, installation steps are subject to change.

Clone the repository:

```bash
git clone https://github.com/Mellophos/horse-racing-sim.git
```

Run `main.py`:

```bash
python main.py
```

Note that results will output to the terminal.
